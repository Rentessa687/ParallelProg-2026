# ParallelProg-2026

Лабораторные работы по параллельному программированию.

Подробности и результаты конкретной лабораторной работы приведены в её
собственном отчёте:

- [Лабораторная работа 1](./lab1) — последовательная версия. [Отчёт](./lab1/REPORT.md)
- Лабораторная работа 2 — параллельная версия на OpenMP. *(в разработке)*

## О чём репозиторий

Необходимо распараллелить вычислительную задачу с использованием открытых
стандартов параллельного программирования на языке C/C++. Для этого нужно
провести серию тестирований: в первой лабораторной работе — последовательно,
во второй — с помощью стандарта OpenMP, далее — с использованием других
технологий параллельного программирования (MPI и т.д.).

Тема распараллеливания — итерационный метод Якоби для решения системы
линейных алгебраических уравнений `Ax = b`. Каждая новая лабораторная
берёт за основу решатель из предыдущей и переносит основной вычислительный
цикл (двойной цикл по `i, j` при вычислении суммы `Σ a_ij·x_j`) на новую
технологию — меняется только способ и скорость вычисления, а не сам
алгоритм и не формат входных/выходных данных.

Все версии решателя на одних и тех же входных данных обязаны находить
одно и то же решение `x` (с точностью до `eps`) — сравнивается только
время работы.

## Методика эксперимента

Для каждого размера задачи `n` генерируется тестовая диагонально
доминирующая СЛАУ (`generate_data.py`), решатель запускается через
`benchmark.py`, результаты усредняются по нескольким запускам и попадают
в `results.csv` соответствующей лабораторной работы.

### Замер

Секундомер (`std::chrono::high_resolution_clock`) включается
непосредственно перед циклом итераций метода Якоби и выключается сразу
после его завершения. Чтение входного файла и запись результата в замер
не входят.

### Верификация

После каждого запуска решение сверяется скриптом `verify.py` с эталоном,
полученным через `numpy.linalg.solve` (LAPACK). Критерий прохождения —
относительная L2-ошибка меньше `1e-4`.

## Требования

- Компилятор C++ (GCC/Clang), поддержка C++17;
- `make`;
- Python 3.10+, пакеты `numpy`, `matplotlib`.

## Быстрый старт (на примере лабораторной работы 1)

```bash
cd lab1
make
python3 generate_data.py 2000 input.txt
./jacobi input.txt output.txt 1e-8 100000
python3 verify.py input.txt output.txt
```
