# Лабораторная работа 3: метод Якоби (MPI)

Параллельная версия решателя из [лабораторной работы 1](../lab1) на MPI.
Формат входных и выходных данных не изменился; в выходной файл добавлены
строки `processes <P>` и `scatter_ms <t>`.

## Состав

| Файл               | Назначение                                                          |
|--------------------|----------------------------------------------------------------------|
| `jacobi_mpi.cpp`   | Метод Якоби на MPI: строки матрицы делятся между процессами          |
| `generate_data.py` | Генерация диагонально доминирующей СЛАУ                              |
| `verify.py`        | Верификация через `numpy.linalg.solve`                               |
| `gen_all.sh`       | Генерация входных файлов `data/input_<n>.txt` для всех размеров      |
| `bench.sbatch`     | Slurm-скрипт серии замеров для одного числа процессов                |
| `submit_all.sh`    | Постановка в очередь задач для `P = 1 2 4 8 16`                      |
| `analyze.py`       | Сводка результатов, таблицы и графики                                |
| `Makefile`         | Сборка `jacobi_mpi` через `mpicxx`                                   |
| `results/`         | Исходные замеры с кластера (`res_<P>.csv`)                           |
| `results_summary.csv`, `results_plot.png` | Итоговая сводка и графики                     |

## Реализация

Процесс 0 читает данные и раздаёт блоки строк `A` и `b` через `MPI_Scatterv`.
На каждой итерации каждый процесс вычисляет свою часть `x_new`, затем
`MPI_Allgatherv` собирает полный вектор, а `MPI_Allreduce` суммирует части нормы
разности для критерия останова. Невязка считается распределённо
(`MPI_Reduce`). Время замеряется только для цикла итераций.

## Сборка

Локально (OpenMPI):

```bash
brew install open-mpi
make
```

На кластере «Сергей Королёв»:

```bash
module load intel/mpi4
make
```

Старый `g++` на кластере не поддерживает C++17, поэтому в `Makefile` указан
`-std=c++11`.

## Запуск

```bash
python3 generate_data.py 2000 input.txt 42
mpirun -np 4 ./jacobi_mpi input.txt output.txt 1e-6 100000
python3 verify.py input.txt output.txt
```

Параметры: `<input_file> [output_file] [eps] [max_iter]`. Число процессов
задаётся `mpirun -np`.

## Серия экспериментов на кластере

Входные данные генерируются на машине с NumPy и копируются на кластер
в `data/`:

```bash
./gen_all.sh
scp -r data <login>@sk.ssau.ru:lab3/
```

Запуск на кластере:

```bash
module load intel/mpi4
make
./submit_all.sh
```

Каждая задача запрашивает один узел целиком группы `mem32` (16 ядер) и пишет
результаты в `results/res_<P>.csv`. После завершения всех задач:

```bash
python3 analyze.py
```
