# Лабораторная работа: метод Якоби (последовательная версия)

Baseline-реализация для дальнейшего распараллеливания (OpenMP в лаб. №2 и т.д.).

## Состав проекта

| Файл               | Назначение                                                        |
|---------------------|--------------------------------------------------------------------|
| `jacobi.cpp`        | Последовательный решатель СЛАУ методом Якоби (C++)                |
| `generate_data.py`  | Генерация тестовой диагонально доминирующей СЛАУ                  |
| `verify.py`         | Автоматизированная верификация результата через NumPy/LAPACK      |
| `Makefile`          | Сборка                                                             |

## 1. Сборка

```bash
make
```

Это создаст исполняемый файл `jacobi`.

## 2. Генерация входных данных

```bash
python3 generate_data.py <n> [input_file] [seed]
# пример:
python3 generate_data.py 1000 input.txt 42
```

Матрица генерируется диагонально доминирующей — это достаточное условие
сходимости метода Якоби. Дополнительно сохраняется точное решение
`x_true` (использованное при генерации `b = A @ x_true`) в файл
`<input_file>.x_true.npy` — для независимой сверки.

## 3. Запуск решателя

```bash
./jacobi <input_file> [output_file] [eps] [max_iter]
# пример:
./jacobi input.txt output.txt 1e-8 100000
```

Параметры:
- `eps` — критерий останова: норма разности `||x_new - x_old||` (по умолчанию 1e-6)
- `max_iter` — максимальное число итераций (по умолчанию 100000)

В `output.txt` записываются: решение `x`, число итераций, время выполнения
(мс), невязка `||Ax - b||`, использованный `eps` и размер задачи.
Время замеряется через `std::chrono::high_resolution_clock` **вокруг цикла
итераций** (без учёта чтения/записи файлов).

## 4. Верификация

```bash
python3 verify.py input.txt output.txt
```

Скрипт независимо решает ту же СЛАУ через `numpy.linalg.solve` (LAPACK)
и сравнивает с решением из `output.txt`: относительная L2-ошибка и
максимальная абсолютная ошибка. Если рядом есть `x_true.npy` —
сравнивает и с точным решением, использованным при генерации данных.
Критерий прохождения: относительная ошибка < `1e-4` (код возврата 0/1
удобен для автоматизации, например в CI или batch-скрипте для серии
экспериментов).

## 5. Пример полного цикла

```bash
make
python3 generate_data.py 2000 input.txt
./jacobi input.txt output.txt 1e-8 100000
python3 verify.py input.txt output.txt
```

## Замечания для отчёта по лабораторной

- **Объём задачи** — размер матрицы `n` (записывается в `output.txt` как
  `problem_size`); квадратичная сложность памяти O(n²), кубическая по
  общему числу операций за все итерации — O(k·n²), где k — число итераций.
- Для построения графиков зависимости времени от `n` удобно прогнать
  серию: `for n in 100 500 1000 2000 4000; do ...; done` и собрать
  `time_ms` из каждого `output.txt`.
- В последующих лабораторных работах именно двойной цикл по `i, j` внутри
  итерации метода Якоби (вычисление `sigma`) — основной кандидат на
  распараллеливание через `#pragma omp parallel for`.
